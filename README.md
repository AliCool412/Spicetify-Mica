# Spicetify Mica

Author : [Ali Cool](https://github.com/AliCool412)

## About

A theme that basically turns all background elements transparent to allow for Windows 11 Mica Backdrop, dark mode only.

Special Thanks to [Ingan121](https://github.com/Ingan121) for helping make this theme work as intended!

Works as intended on versions 1.3.0 through 1.3.6

### Necessary Plugins

- **Windhawk**
To install the [CEF/Spotify Tweaks](https://windhawk.net/mods/cef-titlebar-enabler-universal) mod.
- **Transparency Injector**
Either "[MicaforEveryone](https://github.com/MicaForEveryone/MicaForEveryone)" or "[Translucent Windows](https://windhawk.net/mods/translucent-windows)" windhawk mod will do the trick.

### Required CEF/Spotify Tweaks

- **Enable transparent rendering**
  To allow for transparency, obviously.
- **Disable forced dark mode**
  Spotify by default adds a dark tint to the window, keeping that enabled will impact the transparency.
