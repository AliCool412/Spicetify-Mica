# Spicetify Mica

Author : [Ali Cool](https://github.com/AliCool412)

## About

A theme that basically turns all background elements transparent to allow for Windows 11 Mica Backdrop.

Best used with the "CEF/Spotify Tweaks" Windhawk mod to allow the transparent rendering, or however you can enable transparent rendering otherwise.

Special Thanks to [Ingan121](https://github.com/Ingan121) for helping make this theme work as intended! he also made the Windhawk mod mentioned above.

Works as intended on versions 1.3.0 through 1.3.6

### Required CEF/Spotify Tweaks

- **Enable transparent rendering**
  To allow for transparency, obviously.
- **Disable forced dark mode**
  Spotify by default adds a dark tint to the window, keeping that enabled will impact the transparency.
